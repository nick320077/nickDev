# Manrope

Official variable font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope), designed by Mikhail Sharanda and distributed under the [SIL Open Font License](./OFL.txt).

`Manrope-Variable.ttf` is the unmodified `Manrope[wght].ttf` from the Google Fonts repository, renamed for a simple local path. It includes variable weights 200–800, Latin and Cyrillic character sets, Ukrainian letters and the hryvnia sign.

The app uses `next/font/local`: the font is served by the store, with no Google Fonts requests at build time or in the browser.
